# Calculadora Web

Este projeto é uma calculadora web que desenvolvi para praticar a comunicação entre uma interface HTML e um backend em Python com Flask. Meu objetivo principal foi entender o caminho completo de uma interação: a pessoa clica em um botão, o formulário envia os dados ao servidor, o Flask processa a ação e a página apresenta a resposta.

A calculadora tem um visor, botões numéricos, operações de adição, subtração e multiplicação, além da opção de limpar a interação. Os formulários são enviados pelo método `POST`, e os valores da operação são mantidos em uma sessão Flask entre as requisições.

## O que pratiquei

- Estruturação da interface com HTML e estilização com CSS.
- Recebimento e leitura de dados enviados por formulários no Flask.
- Uso de sessões para manter o estado entre requisições.
- Renderização de dados do backend em um template HTML.
- Versionamento do projeto com Git.

Desenvolvi o projeto individualmente e sem auxílio de ferramentas de inteligência artificial. Usei o processo para aprender Flask na prática, especialmente o envio e o recebimento de formulários e a integração entre frontend e backend.

## Tecnologias

- Python
- Flask
- HTML
- CSS
